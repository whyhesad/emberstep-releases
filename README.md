# Emberstep

Лаунчер и экспериментальные сборки игры для Windows x64 и macOS Universal.

## Скачать

[Открыть страницу сборок](https://github.com/whyhesad/emberstep-releases/releases)

Выберите ZIP лаунчера для своей ОС в разделе Assets опубликованного релиза. Распакуйте архив полностью и откройте Emberstep Launcher. В Windows файл .pck должен оставаться рядом с .exe.

В лаунчере нажмите «Установить» и подтвердите скачивание. Он загрузит игру, проверит подпись и файлы, затем покажет «Играть». Части .part и manifest вручную скачивать не нужно. После установки одиночная игра доступна без интернета. Аккаунт для скачивания и игры не нужен.

## Статус

Это прототип, не сертифицированная публичная бета. Mac-сборка имеет только ad-hoc подпись, без Developer ID/notarization: Gatekeeper может заблокировать запуск. Не отключайте системную защиту. Windows x64 экспортирована, но запуск на реальном Windows ещё не проверен; Authenticode отсутствует.

PvP работает только по LAN. Лаунчер обновляется вручную. Приватные ключи, сохранения и исходный рабочий проект сюда не загружаются.

[Сообщить об ошибке](https://github.com/whyhesad/emberstep-releases/issues/new) — для обращения нужен GitHub-аккаунт. Диагностика сохраняется локально по вашей команде и автоматически не отправляется.
